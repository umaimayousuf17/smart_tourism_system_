# Smart Tourism System 🌍🧳

## 📌 Project Overview
The **Smart Tourism System** is an AI-powered application designed to enhance and optimize the travel planning experience. Developed as an Operational Evaluation Lab (OEL) project for Artificial Intelligence, this system leverages core AI search strategies and decision-making logic to help users find optimal paths, explore destinations, and receive customized itinerary recommendations based on user constraints.

## 🚀 Key Features
* **Optimal Route Discovery:** Utilizes informed or uninformed search algorithms to find the shortest and most cost-effective travel paths between tourist locations.
* **Intelligent Recommendations:** Uses rule-based logic or pattern matching to suggest destinations, accommodations, and activities based on dynamic user preferences.
* **Interactive Interface:** Designed to provide a user-friendly experience for feeding dynamic inputs and generating quick, efficient solutions.

## 🛠️ Tech Stack
* **Language:** Python 🐍
* **Concepts:** Artificial Intelligence Search Algorithms, Pattern Matching, Knowledge Representation.
